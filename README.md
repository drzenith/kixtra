# Kixtra

A no-login Android frontend for [Kick](https://kick.com), inspired by [Xtra](https://github.com/crackededed/Xtra).

- **Better player:** quality picker (incl. audio only) and speeds up to 4x, both remembered
- **Rewindable live streams:** scroll back anytime, then catch up to live at 2–4x
- **Resume anywhere:** VODs and live streams pick up where you left off, even after the stream ends
- **Chat:** live chat and synced VOD chat replay, as a sidebar or an overlay on the video
- **Local follows, search and browsing,** no account needed

Download the latest APK from [Releases](https://github.com/drzenith/kixtra/releases/latest).
